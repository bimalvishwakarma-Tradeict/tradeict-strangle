   PER LEG (same qty on call and put).
   auto_trade_engine.py:2998-3059 (pct_of_hedge path):

   So hedge_qty_lots=4 → 4-lot long call + 4-lot long put (not 4 total).

5) Roll timing — hedge_roll_dte / hard / min_hold
   CODE DEFAULTS (models.py / routes_auto_trade.py Field defaults):

   hedge_min_hold_days default=10 (models.py ~422; routes_auto_trade.py:95)
   LIVE DB values: NOT AVAILABLE in this repo session (no trading.db here) — do not assume.
   TASK / S001_CONFIG_SEMANTICS.md §6 EXAMPLE values: roll_dte=3, hard_dte=2, min_hold=10.
   Exact roll behaviour (hedge_lifecycle.py:3183-3263):
   - calendar_dte <= roll_dte and status=active → status=pending_close
   - pending_close + calendar_dte <= hard_dte + force enabled → close HEDGE_ROLL
   - pending_close + zero open baskets → close HEDGE_ROLL (soft execute)
   - pending_close + open baskets + dte > hard → WAIT (do not close yet)
   min_hold blocks STRUCTURE TARGET only (hedge_lifecycle.py:2841-2890); does NOT block roll/SL/expiry.
